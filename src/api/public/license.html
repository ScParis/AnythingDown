Agradecimentos ao Ecossistema Open Source

O AnythingDown foi construído graças à dedicação de projetos e mantenedores incríveis do mundo do software livre:

  • yt-dlp: O motor mais poderoso do mundo para extração de áudio e vídeo na web.
  • FFmpeg: A suíte completa e universal para conversão e processamento de formatos multimídia.
  • Node.js & TypeScript: A base robusta, veloz e tipada que orquestra toda a aplicação.
  • Express & CORS: Framework de alta performance para a camada de API REST e entrega de streaming.
  • Baileys: Implementação aberta do protocolo WhatsApp Web multi-device.
  • grammY: Framework moderno e elegante para bots do Telegram.
