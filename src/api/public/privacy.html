Política de Privacidade

ÚLTIMA ATUALIZAÇÃO: OUTUBRO DE 2026 // EM CONFORMIDADE COM LGPD E GDPR

A sua privacidade é um princípio fundamental no AnythingDown. Esta política esclarece de forma transparente como nosso serviço, API e robôs lidam com as informações quando você utiliza nossa plataforma.

1. Não Coletamos Dados Pessoais

O AnythingDown foi projetado seguindo o princípio da Privacidade por Design (Privacy by Design) e minimização estrita de dados:

  • Sem cadastro ou login: Você não precisa informar nome, e-mail, telefone, CPF ou qualquer dado pessoal para usar o serviço.
  • Sem criação de perfis: Não rastreamos histórico individual de downloads, não geramos perfis comportamentais e não vendemos dados para redes de publicidade.
  • Sem cookies de rastreamento: Não utilizamos cookies de terceiros para publicidade ou monitoramento invasivo.

2. Processamento Efêmero de URLs e Mídias

Quando você submete um link de vídeo ou post para download:

  • A URL é transmitida de forma criptografada via HTTPS para o endpoint de processamento.
  • O arquivo temporário é gerado estritamente para conversão de formato e envio do stream via HTTP diretamente ao seu navegador ou app.
  • Descarte imediato: Assim que o stream de download é concluído ou a conexão é encerrada, o arquivo temporário é automaticamente removido do disco do servidor por funções de limpeza imediata.
Zero Persistência de Mídia: Não mantemos cópias, logs permanentes ou histórico das mídias processadas. A memória e disco do servidor operam em ciclo contínuo de limpeza em tempo real.

3. Armazenamento Local no Navegador (LocalStorage)

Utilizamos apenas o mecanismo nativo de localStorage do seu navegador para guardar suas preferências de navegação local, tais como:

  • anythingdown_theme: Tema visual escolhido (Tron '82, Cyberpunk 2077, Top Gear '92, Counter-Strike, GTA VI ou Spider-Noir).
  • anythingdown_sfx: Preferência de efeitos sonoros ativados ou desativados.

Essas informações ficam salvas apenas no seu próprio dispositivo e nunca são enviadas para nossos servidores.

4. Privacidade nos Bots (Telegram e WhatsApp)

Telegram Bot: Ao interagir com o bot pelo Telegram, o bot recebe unicamente os links enviados no chat privado para realizar a extração e responder com o arquivo. Nenhuma conversa é arquivada.

WhatsApp Bot: O bot para WhatsApp utiliza conexão direta via biblioteca Baileys. O pareamento por QR Code é autenticado diretamente entre o seu telefone e o terminal local. O código-fonte é 100% aberto para auditoria independente.

5. Transparência e Código Aberto

O AnythingDown é um projeto público e de código aberto. Toda a lógica de servidor, API e tratamento de arquivos pode ser livremente examinada no repositório no GitHub.
