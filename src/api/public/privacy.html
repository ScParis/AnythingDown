A sua privacidade é um pilar inegociável no AnythingDown. Esta política esclarece como nosso serviço, API e robôs operam com estrita minimização e proteção de dados.

1. Zero Coleta de Dados Pessoais

O AnythingDown foi construído sob o princípio de Privacy by Design:

  • Sem cadastro ou login: Não solicitamos nome, e-mail, telefone, senhas ou documentos.
  • Sem rastreamento comportamental: Não mantemos histórico pessoal de downloads nem vendemos informações para redes de anúncios.
  • Sem cookies de monitoramento: Não utilizamos pixels de publicidade ou rastreadores de terceiros.

2. Processamento Efêmero de URLs e Mídias

Ao colar e processar um link:

  • A URL é enviada com criptografia de ponta a ponta via HTTPS ao servidor de conversão.
  • O arquivo temporário gerado para conversão existe apenas durante a transmissão do stream de download.
  • Limpeza Imediata: Assim que o download é finalizado ou a requisição é encerrada, os dados temporários são automaticamente excluídos do disco.
Sem Banco de Mídias: Não mantemos arquivos de vídeos ou áudios guardados em servidores. O armazenamento é 100% volátil e efêmero.

3. Preferências Locais (LocalStorage)

Utilizamos unicamente o localStorage do seu navegador para guardar suas preferências visuais e acústicas na máquina:

  • anythingdown_theme: Tema selecionado (Tron, Cyberpunk, Top Gear, CS, GTA VI ou Spider-Noir).
  • anythingdown_sfx: Efeitos sonoros ativados ou silenciados.

Nenhuma dessas preferências sai do seu navegador.

4. Robôs Integrados (Telegram e WhatsApp)

Telegram Bot: Processa apenas o comando/link enviado no chat para retornar o arquivo direto pelo Telegram.

WhatsApp Bot: O pareamento por QR Code ocorre exclusivamente entre o seu aparelho e seu ambiente local, com o código aberto disponível no GitHub para auditoria.

5. Transparência Open Source

Todo o projeto AnythingDown é mantido de forma pública e transparente por ScParis.
